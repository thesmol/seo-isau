## Локальный запуск

```sh
npm ci
npm run dev
```

Откройте адрес, показанный Vite (обычно `http://127.0.0.1:5173/`). Для AJAX и XML используйте HTTP, а не `file://`.

Для сборки и проверки статической публикации:

```sh
npm run build
npm run preview
```

Нужен Node.js 20.19+ или 22.12+. Сборка Vite сохраняет исходные HTML, CSS, JavaScript, XML и медиа без изменения: это важно для сравнения размеров jQuery, AMP-валидации и самостоятельности этапов. Для замеров используйте `preview`, потому что `dev` добавляет служебный клиент Vite.

## Условия заданий

Ниже приведён полный текст соответствующих заданий из предоставленной постановки. Пути `addons/...` относятся к исходному учебному комплекту.

### Задание №2

```text
Сохранить главную страницу сайта saudubna.ru на свой компьютер, при необходимости скачать в ручном режиме недостающие файлы.

Переделать исходную верстку сайта с использованием модели flexbox. Сохранение полного функционала сайта (выпадающие меню, слайдер и т.п.) не требуется.

Загрузить исходную и переделанную страницы на внешний хостинг. Провести сравнение метрик отображения сайта с помощью PageSpeed Insights, объяснить полученные результаты.

Исходные данные: сайт saudubna.ru

Приложение: см. addons/task2/isau_template.ZIP
```

### Задание №3

```text
Для результата рабочего задания 2 необходимо разработать адаптивную верстку (css-код) для основных устройств (телефон, планшет, десктоп). Точки смены оформления выбираются студентом самостоятельно. Выбор этих точек потребует обоснования при проверке результата.

Загрузить адаптивную версию страницы на внешний хостинг. Провести сравнение метрик отображения адаптивной версии и страниц из задания 2 с помощью PageSpeed Insights (https://pagespeed.web.dev/), объяснить полученные результаты.

Исходные данные: результат выполнения задания №2 (html и css коды)
```
